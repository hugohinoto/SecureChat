# SecureChat 利用説明書

> 対象: SecureChat v0.6.0 / Crypto Protocol v2  
> この説明書は一般ユーザー向けです。画面や利用条件は今後の更新で変わる場合があります。

## 1. SecureChatでできること

SecureChat Labでは、招待制の1対1チャットを利用できます。ワークスペースからSecureDropへ移動すると、相互確認済みの連絡先と暗号化ファイルを送受信できます。

- **チャット**: 1対1のテキストメッセージ。メッセージは送信から1時間後に削除されます。
- **SecureDrop**: チャットとは別のファイル転送機能。ファイルは送信側ブラウザーで暗号化してから送信します。
- **ワークスペース**: サイドバーの「チャット」「SecureDrop」で機能を切り替えられます。
- **表示言語**: チャット、SecureDrop、管理画面、バグ報告画面は日本語/英語に切り替えられます。各画面上部の言語選択で変更でき、設定はこのブラウザーに保存されます。初期設定は日本語です。

## 2. アカウントを作成する

SecureChatは招待制です。アカウントを持つ人から登録用招待コードを受け取ってください。

1. SecureChatのログイン画面を開き、「新規登録」を選びます。
2. ユーザーIDを入力します。半角英数字とアンダースコアを使った3〜32文字です。
3. 12〜128文字のパスワードを設定します。
4. 受け取った招待コードを入力し、「アカウントを作成」を押します。
5. 登録後は、同じユーザーIDとパスワードでログインします。

### 自分から登録用招待コードを発行する

1. ログイン後、左サイドバーの「アカウント招待」を開きます。
2. 「新しい招待コードを発行」を押します。
3. 表示されたコードを、招待したい相手に安全な方法で共有します。

登録用招待コードは**24時間有効・1回限り**です。有効なコードは最大5件まで発行できます。コードを公開の場所へ投稿しないでください。

## 3. 連絡先を追加する（双方の8桁コード確認）

チャットやSecureDropを利用するには、相手との相互確認を完了する必要があります。ユーザーIDを検索しただけでは連絡先になりません。

1. 左サイドバーの「ユーザーを検索」に相手のユーザーIDを入力し、「検索」を押します。
2. 検索結果で相手を確認し、「招待コード発行」を押します。
3. 表示された8桁コードを相手本人に、電話など別の安全な経路で伝えます。コードは5分以内に共有してください。
4. 相手は自分の「ワンタイムコード招待」欄で、受け取った8桁コードを入力して「承認」を押します。
5. 相手は同じ招待欄から「確認コードを発行 / 再発行」を押し、新しく表示された8桁コードをあなたへ伝えます。
6. あなたは自分の招待欄に相手の8桁コードを入力し、「最終確認」を押します。
7. 「相互確認が完了」と表示され、連絡先一覧に相手が表示されたら完了です。

コードは本人確認のためのものです。相手のユーザーIDを別の経路でも確認し、コードを第三者へ転送しないでください。期限切れや入力回数超過の場合は、新しい招待からやり直してください。

## 4. チャットを使う

1. 左サイドバーの「連絡先」または「メッセージ」から相手を選びます。
2. 画面上部の暗号化方式と状態を確認します。
3. 入力欄にメッセージを入力し、「送信」を押します。Enterでも送信できます。改行はShift + Enterです。
4. 送信できない場合は、接続状態・暗号化状態・表示されたエラーコードを確認してください。

- 1メッセージは最大2,000文字です。
- メッセージは送信から1時間後に削除されます。
- 現在の画面は1対1のテキストチャットです。
- ブラウザー通知は「ブラウザー通知を有効にする」から許可できます。通知を許可しなくてもチャットは利用できます。

### 暗号化方式の表示について

会話を選択すると、画面上部にその会話で使われている方式が表示されます。

- **前方秘匿性v2 / RATCHET v2**: 端末別のOlm / Megolm方式です。相互OTP確認済み連絡先の初回署名鍵をこのブラウザーで自動的に信頼し、双方の端末登録後にV2移行・鍵交換を自動で行います。
- **v1 / FSなし**: 旧方式です。会話単位の長期鍵を使い、前方秘匿性はありません。

連絡先追加時に双方が電話など別経路で8桁OTPを確認しているため、その相互確認済み連絡先に限り、初回の署名鍵をこのブラウザーへ自動でピン留めします。双方の端末が準備できると、V2への切り替えと鍵交換、以後のメッセージ鍵更新が自動で行われます。署名鍵が変更された場合は自動で信頼せず、電話・対面など別経路で新しい指紋を確認するまで接続を停止します。

この自動信頼はサーバーが返す相互OTP連絡先情報に依存します。悪意あるサーバーが初回の連絡先状態や鍵を偽装する場合の本人確認を提供するものではありません。サーバーからの独立した本人確認が必要な状況では、初回も相手の指紋を別経路で照合してください。

### 端末・ブラウザーを変更するときの注意

暗号鍵は端末・ブラウザー内にも保存されます。ブラウザーのサイトデータやCookie、ローカルストレージを不用意に削除しないでください。元の端末を失ったり、サイトデータを消したりすると、過去の会話やSecureDropファイルを復号できなくなることがあります。新しい端末で鍵の警告が出た場合、むやみに新しい鍵を作成せず、元の端末のデータを保持したまま管理者へ相談してください。

## 5. SecureDropでファイルを送る

SecureDropはチャットとは別のファイル転送画面です。送信側・受信側の両方がログインし、相互確認済み連絡先である必要があります。

1. ワークスペースの「SecureDrop」を開きます。
2. 「ファイル送信」で送信先を選択します。
3. 「ファイルを選択」を押し、送るファイルを選びます。
4. 通常送信または「優先送信」を選びます。優先送信は通常送信の5倍のクレジットを使用します。
5. 「暗号化して送信」を押します。
6. 完了メッセージと消費クレジットを確認します。

### 送信時の容量・クレジット

- 1ファイルの上限は**25 MB**です。
- 月ごとの基本付与は**100クレジット**で、翌月への繰り越しはありません。
- 通常送信は暗号化後の保存サイズを基準に、1 MBごとに1クレジット（端数切り上げ、最低1クレジット）を使用します。
- 優先送信は通常送信の5倍のクレジットを使用します。
- 専用容量は2.5 GBです。使用率が90%に達すると通常送信は一時停止します。優先送信は通常送信停止時の容量確保・送信に使う選択肢ですが、空き容量やクレジットがなければ送信できません。
- ファイルの期限はアップロードから7日、または日本時間の月末までの早い方です。

クレジットや容量は「利用状況」タブで確認できます。送信が止まった場合は残高と使用容量を確認してください。

### 送信が保留された場合

通信切断や容量調整などで送信が完了しなかったファイルは、「端末内の再送信待ち」に表示されることがあります。

1. SecureDropを開き直し、「再送信待ち」タブを確認します。
2. 対象ファイルの「再送信」を押します。
3. 通常送信が停止されている場合などは「優先で再送信」または「通常で再送信」が表示されます。必要なクレジットを確認して選択してください。

保留データは送信したブラウザーの端末内に一時保存されます。送信完了を確認する前に、サイトデータを消去したりブラウザーの保存データを削除したりしないでください。端末故障やデータ消去から保留ファイルを復元することはできません。

## 6. SecureDropでファイルを受け取る

1. SecureDropの「ファイル一覧」を開きます。
2. 「受信ファイル」と表示されたファイルを確認します。
3. ファイル名・送信者・期限・残り無料回数を確認します。
4. 「取得・復号」を押します。取得したファイルはブラウザー内で復号され、端末へ保存されます。

### ダウンロード料金

- 1ファイルにつき最初の**3回は無料**です。
- 4回目以降は、**受信者**のクレジットを使用します。
- 料金は暗号化後のファイルサイズを基準に、1 MBごとに1クレジット（端数切り上げ、最低1クレジット）です。
- 有料ダウンロードの前に確認画面が表示されます。表示された消費クレジットを確認し、続行する場合だけ承認してください。
- クレジット不足の場合はダウンロードできません。

ファイル一覧の「更新」を押すと、一覧と利用状況を再読み込みできます。期限切れ・削除済みのファイルは取得できません。

### ファイルを削除する

送信したファイルには「削除」ボタンが表示されます。削除すると受信者もダウンロードできなくなります。削除確認をよく読んでから実行してください。

## 7. ログアウト・アカウント削除

- **ログアウト**: 左サイドバー下部のログアウトボタンを押します。共有端末では利用後にログアウトしてください。
- **アカウント削除**: 「アカウントを削除」を押し、確認画面と現在のパスワード入力に進みます。アカウント、連絡先、個別チャット、暗号化メッセージが削除され、取り消せません。必要なデータや鍵を確認してから実行してください。

## 8. 困ったときは

| 表示・症状 | 確認すること |
|---|---|
| ログインが必要です | SecureChat Labでログインし直してください。 |
| 相互確認済み連絡先ではありません | 連絡先追加の8桁コード確認を最後まで完了してください。 |
| コードの期限切れ | 招待した側に新しいコードを発行してもらってください。 |
| 暗号鍵を確認できません | 元の端末・ブラウザーのサイトデータを消さずに管理者へ相談してください。 |
| 前方秘匿性v2へ移行しない | 相互OTP確認が双方で完了しているか、相手側の端末がオンラインか確認してください。署名鍵変更の警告がある場合は、相手本人と別経路で指紋を照合してください。 |
| クレジット不足 | 利用状況を確認してください。翌月の付与まで繰り越しはありません。 |
| 通常送信が停止中 | 専用容量の使用率を確認してください。優先送信は通常の5倍のクレジットを使用します。 |
| ダウンロード上限・期限切れ | 無料3回を使い切っていないか、ファイルの期限が切れていないか確認してください。 |
| エラーコードが表示される | エラーコードと発生した操作を控え、管理者へ伝えてください。パスワード・招待コード・OTP・秘密鍵は送らないでください。 |

## 9. セキュリティ上の重要な注意

SecureChatは開発中のプロトタイプです。Crypto v2やSecureDropは実装されていますが、独立した専門家によるセキュリティ監査、複数ユーザー・複数端末での実環境検証、鍵の復旧・失効に関する検証がすべて完了しているわけではありません。**安全性を保証するものではありません。**

- パスワード、認証コード、OTP、秘密鍵、復旧情報を他人に教えないでください。
- SecureChat運営を名乗る人からパスワードやOTPを求められても渡さないでください。
- 重要な認証情報、金融情報、極めて機密性の高い情報の送信には使用しないでください。
- 暗号化は、端末自体のマルウェア感染・盗難・画面撮影・保存済みデータの窃取を防ぐものではありません。
- SecureDropのファイルは、受信者が復号できる鍵を保持する端末で取得してください。別端末に鍵がない場合、復号できないことがあります。
- ファイルの期限切れや削除はアプリ側の保存データを対象とします。バックアップ等の保持期間まで即時消去されることを保証するものではありません。

安全に利用するため、画面上部の暗号化状態とファイル取得前のクレジット確認を毎回確認してください。
