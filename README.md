# SecureChat

プライバシーを重視した、ブラウザー向けセキュアチャットの開発プロジェクトです。

> [!WARNING]
> **現在は開発用プロトタイプです。E2EE・アカウント認証・個別チャットは未実装です。**
> 現段階のテストルームでは、メッセージ本文がサーバーを経由して平文で全接続者に中継されます。パスワード、個人情報、機密情報は絶対に送信しないでください。

## 現在の実装

- Liquid Glass風のレスポンシブなチャットUI
- Node.js / ExpressによるWebサーバー
- WebSocketによるリアルタイムの共通テストルーム
- 表示名の設定（このブラウザーのlocalStorageに保存）
- メッセージ文字数制限・送信頻度制限
- 同一オリジンのWebSocket接続チェック
- 基本的なブラウザー向けセキュリティヘッダー
- Render Blueprint（render.yaml）

メッセージはサーバー上に保存されません。ただし、これはE2EEを意味しません。通信経路とサーバーではメッセージ本文を読める状態です。

## 必要環境

- Node.js 26.13.1
- npm

## ローカルで起動

```bash
npm install
npm run dev
```

ブラウザーで http://localhost:3000 を開きます。

通常起動は次のコマンドです。

```bash
npm start
```

環境変数は .env.example を参考に設定してください。.env はGitにコミットしないでください。

## セキュリティ原則

- 独自の暗号アルゴリズムや独自の鍵交換プロトコルを作りません。
- 秘密鍵・セッション鍵・復号済みメッセージをサーバーに渡さない設計を目指します。
- パスワードは適切なパスワードハッシュで保存します。
- 暗号化状態を画面上で明確に区別し、未暗号化状態を安全だと誤認させません。
- E2EEの完成や安全性は、十分なテストとレビューが済むまで保証しません。
