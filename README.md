# SecureChat

プライバシーを重視した、ブラウザー向けセキュアチャットの開発プロジェクトです。

> **開発初期段階です。** 現時点では、実運用できるエンドツーエンド暗号化（E2EE）は実装されていません。機密情報や実際の個人間通信には使用しないでください。

## 目標

- HTML / CSS / JavaScript によるレスポンシブな Liquid Glass UI
- Node.js による API / WebSocket サーバー
- PostgreSQL によるアカウント・公開鍵・暗号文メタデータの管理
- HTTPS / WSS による通信
- 検証済みの Signal Protocol 実装を利用した E2EE の検討・実装
- Render へのデプロイと GitHub 連携

## セキュリティ方針

- 独自の暗号アルゴリズムや独自の鍵交換プロトコルを作らない。
- パスワードは適切なパスワードハッシュで保存し、平文では保存しない。
- 長期秘密鍵・セッション鍵・復号済みメッセージをサーバーに送信・保存しない設計を目指す。
- 暗号化の実装、鍵管理、端末間同期、バックアップ、XSS 対策を個別に検証する。
- E2EE の完成や安全性を、テスト・レビュー前に保証しない。
